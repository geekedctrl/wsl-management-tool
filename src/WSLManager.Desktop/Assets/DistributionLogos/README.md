# Distribution logos

These locally bundled SVG marks are shown beside recognized WSL distribution names. The app does not fetch artwork at runtime. Unknown distributions use the generic Linux mark.

The icon collection is CC0-1.0; the included marks are trademarks of their respective owners. Simple Icons project and legal disclaimer: <https://github.com/simple-icons/simple-icons> and <https://github.com/simple-icons/simple-icons/blob/develop/DISCLAIMER.md>.

Simple Icons entries included: Alpine Linux, AlmaLinux, Arch Linux, CentOS, Docker, elementary OS, Fedora, Gentoo, Kali Linux, Linux (fallback), Manjaro, openSUSE, Parrot, Red Hat, Rocky Linux, Tails, Ubuntu, and Void Linux. The SVG fill colors are set to each brand's commonly used color; the original path geometry is preserved.
